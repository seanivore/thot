## Bucket Purpose

Decide whether and how Thot ships native apps (macOS, iOS) on top of the web/PWA. Sean's instinct (per `UPDATE_v4_0_0.md`): the web app is the headline; native apps are bonus surfaces that "drop in" the web app when updates ship, without parallel maintenance burden.

---

## Initial Research Questions

1. **SwiftUI wrapper feasibility — modular drop-in PWA pattern.** Can a SwiftUI app host a `WKWebView` pointed at the deployed web app, with the native shell adding system integrations the web can't reach? When the web app updates, the native app gets the update for free. Tradeoffs:
   - Pros: zero parallel codebase, fast iteration on web → native carries through, Apple-only integrations available.
   - Cons: WKWebView quirks, Apple review for any feature that touches their APIs, limited offline.
2. **Native-without-App-Store paths** — does every macOS app require App Store submission and a paid developer account? Or can a SwiftUI wrapper be distributed as a notarized DMG outside the store? (For macOS yes; for iOS no.)
3. **macOS toolbar/notch jot pad** — Sean's "lives in the menubar, hover to capture" idea. Quick-capture surface that doesn't context-switch the user out of their workflow. SwiftUI menubar apps are well-supported. What's the data model — does the jot pad write to the same persistence layer as the web app?
4. **iOS-specific affordances** — Apple Pencil handwriting → text, Live Activities, Widgets, Lock Screen, Apple Intelligence integration. Which of these earn the cost of building a native iOS app vs. PWA?
5. **"AI loves to write outdated SwiftUI code"** — Sean noted reputable sources flag this. What's the current SwiftUI landscape in 2026? What patterns/APIs are most commonly mis-generated by AI?
6. **Cross-device sync implications** — native apps must talk to the same `sync-and-cross-device` backend the web does. The architecture choice in that bucket gates this one.
7. **Other languages on Apple platforms?** Sean asked. Yes — Tauri (Rust+web), Electron (web), Flutter (Dart), Kotlin Multiplatform (sort-of). What's the modular-drop-in story for each?

---

## Priors / Known Constraints

- The web/PWA is and stays the source of truth. Native is bonus, not headline.
- Sean has limited Swift/SwiftUI experience and notes that AI tends to generate outdated SwiftUI code — research must verify against current Apple docs, not training-data assumptions.
- This bucket is downstream of `sync-and-cross-device` architecture decisions. Don't lock anything here before that's settled.
