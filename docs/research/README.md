# Thot — Research

The single research directory for the project. Previously split between `docs/research/` (live) and
`docs/archive/research/` (older sketches); merged here 2026-05-20 so there is one place to look.

Phase structure follows `.agent/RESEARCH_PROTOCOL.md`: `1_DEEP` → `2_FOCUS` → `3_FINAL`.

## Layout

- **`1_DEEP/`** — active deep research, one subdirectory per topic.
  - `highlighter-architecture/`, `auth-and-sync/`, `native-wrapper/` — substantive Phase-1 work with
    locked recommendations.
  - `feature-research/` — `FORMATTING_UX.md` and `COLUMNS_LAYOUT.md` (scaffolds awaiting Sean's
    narrative fill-in); `ICONS.md` (icon-consolidation housekeeping).
  - `ai-features/`, `collab-for-markdown/`, `sync-and-cross-device/` — seed `1_REVIEW.md` buckets,
    Phase-1 work not yet started.
- **`2_FOCUS/`, `3_FINAL/`** — later RESEARCH_PROTOCOL phases; populated as `1_DEEP` work consolidates.
- **`business/`** — business-track research (market positioning, monetization). RESEARCH_PROTOCOL-grade
  work; see `business/README.md`.
- **`_superseded/`** — research drafts that were replaced by more current work. Kept, not deleted
  (`.agent/DEV_RULES.md` § "Nothing is deleted"). Not active — do not cite from here.

## History

`_superseded/` and the seed `1_REVIEW.md` buckets originated as Sean's pre-RESEARCH_PROTOCOL sketches
(2026-04). The current protocol-driven `1_DEEP` work was seeded from them.
