**Comment Engagement Assistant for Getting IG Growth**
  + Super helpful automation I used to run
  + Meta Instagram API watch for public image posts
  + Set it to watch creators whose audience is your target market
  + Each time they post create a new entry row in a Google Sheets document
  + Google Sheet columns:
    - Timestamp date (isolate date and format it for easy human visual recognition, e.g. 2/2/26)
    - Timestamp time (isolate time and format it, e.g. 9:10am
    - Equation (= amount of H:MM since timestamp passed current time formatted, e.g. 0h 10m)
    - Account @username
    - Audiencee engagement ranking (= calculation from output data that infers a rating for how engaged their audience is)
    - Caption 
    - Comment Draft - Style Guide A
    - Comment Draft - Style Guide B (etc.)
    - Comment Draft - Objective 1 (etc.)
    - Permalink
    - Opportunity ranking (AI assessment of liklihood of getting engagement on the comment based on uniqueness of content, audience engagement ranking, and assessment of quality of comment content)
    - Opportunity recommendation (which comment draft to post) 
  + Have Claude look at the image and create the comments 
  + Create webhook for Google Sheets/Notion entries so you can comment ASAP after they posted
  + Bonus points would be to have it made FOR REAL mobile-first
    - Provide the copy UI
    - Click link to post
    - Paste link
    - Get notifications right when the influencer posted and there is a comment prepared
  + Though the biggest value for me was
    - Being able to rapidly do them in bulk, commenting on 20 different people's posts in minues
    - And AI constantly recognized references that the user was making (lots of art stuff) that I would never ever have known so it made me way more informed seeming and meant that my comments were providing other users value
