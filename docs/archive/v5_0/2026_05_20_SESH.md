- **Cold-pass verification.** A fresh agent re-checked the densest sources against the integrated doc — 7 more genuine residual gaps found and integrated. Purge confirmed complete.

- **Phase D — Source citations stripped.** All 345 `(source: …)` inline citations removed by script; ~85 residual prose source-attributions removed by an editing pass; WRITER-banner comments and the Document-Provenance placeholder deleted. The document no longer points at the source files it was built from.
- **Phase E — Reorganized.** Sections reordered into a logical sequence (editor-surface features grouped; the data layer dependency-ordered with Authentication before Sync/Collaboration; Preferences placed adjacent to the highlighting cluster); ~8 duplicated feature writeups merged to single homes; misplaced subsections relocated. Confirmed organizationally sound by a fresh full-read review.
- **Phase F — Promoted to `v5_0_0_IMPLEMENT.md`.** The FB-era front matter (Pass 1/2/3 scaffolding, the source-citation convention) was replaced with a proper IMPLEMENT header (Initiative / Revision-driven-by / Roadmap Overview / status-tag legend). Companion outline `v5_0_IMPLEMENT_OUTLINE.md` created.
- **Phase G — Housekeeping.** `thots.md` moved to `processed/`; `docs/THOT_APP.md`'s stale roadmap pointer updated to the new IMPLEMENT; this session doc written.

Result: `v5_0_0_IMPLEMENT.md` — ~4,040 lines, citation-free, feature-area-organized, the active living roadmap. Supersedes `v4_1_0_IMPLEMENT.md`.
